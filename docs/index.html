How it works

From any platform to a loan, in five steps.

Each step says plainly what is live today and what is still being built.

  1. 01Live

    Any platform

    A graded slab listed on a public marketplace, identified by its PSA cert number.

  2. 02Tested locally

    Horizen Vela

    The appraisal engine prices it privately. Raw comps stay sealed; only the result comes out.

  3. 03Live

    Certificate

    A signed price certificate goes onchain: value, range, confidence, risk tier. One token per cert.

  4. 04Being built

    Chainlink

    The same certificate, readable in the Chainlink price-feed format that lending apps already use.

  5. 05Live on testnet

    Robinhood Chain

    A vault reads the certificate and lends stablecoins against the slab.

Our part of the answer

One cert. One token. One checkable value.

  • Every token points at one real PSA cert number.
  • The contract refuses a second token for the same cert.
  • Each cert gets a signed price certificate anyone can verify onchain.

Proving where a slab is stored is the vault's job. We make its value checkable.

Private by design
