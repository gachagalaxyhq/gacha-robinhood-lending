How it works

From any platform to a checkable value, in five steps.

Each step says plainly what is live today and what is still being built.

  1. 01Live

    Any platform

    A graded slab listed on a public marketplace, identified by its PSA cert number.

  2. 02Tested locally

    Horizen Vela

    The appraisal engine prices it privately. Raw comps stay sealed; only the result comes out.

  3. 03Live

    Gacha Mark

    Your card's Gacha Mark goes onchain: value, range, confidence, risk tier. One token per cert.

  4. 04Being built

    Chainlink

    The same certificate, readable in the Chainlink price-feed format that lending apps already use.

  5. 05Mainnet pilot

    Robinhood Chain

    A vault reads the certificate and lends stablecoins against the slab.

Why it works

One cert. One token. One checkable value.

Three rules make the certificate trustworthy.

One cert

Every token points at one real PSA cert number.

One token

The contract refuses a second token for the same cert.

Each cert also gets a signed price certificate anyone can verify onchain. Neither this UI nor token custody proves physical authenticity, storage or legal rights; we make the published value checkable. Values are asking prices, not completed sales.

Values come from the Gacha Galaxy pricing engine and public marketplace listings. They are asking prices, not completed sales. The pricing engine is built for Horizen Vela and tested locally; it is not yet live on Horizen's network. "Chainlink-ready" means the certificate will be readable in the Chainlink price-feed format (reader being built); it is not a Chainlink-delivered feed. Mainnet pilot, not financial advice. Token ownership and a price certificate do not verify physical authenticity, custody, or enforceable rights to a slab. USDG restrictions, upgrades and liquidation can affect exit.
